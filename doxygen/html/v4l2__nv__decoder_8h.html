Detailed Description

NVIDIA NVDEC V4L2 Decoder implementation.

Author
Sampsa Riikonen
Date
2025
Version
1.6.1

Uses the stateful V4L2 M2M API for hardware decoding. Works with:

  • vicodec (virtual codec for testing, uses FWHT)
  • Jetson hardware decoders (H.264, H.265)
  • Other V4L2 M2M capable devices

Codec identity (fourcc) and initial dimensions are pulled from the AVStream passed at construction. V4L2NVDecoderParams holds only backend configuration (device path, buffer counts, DMA target).
