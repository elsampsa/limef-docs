Detailed Description

Frame containing either decoded video, audio data or both.

A unified frame class for handling both decoded video and audio frames. Contains two pre-allocated AVFrames that adapt to the maximum required size for their respective media types. Works with the FrameFifo pre-allocated stack system for efficient memory management.

Has both video and audio interal AVFrame's of which either one is active.

Usage example:

DecodedFrame* frame = framefifo.getFrame();
// For video
if (frame->reserveVideo(1920, 1080, AV_PIX_FMT_YUV420P)) {
// frame ready for video data
}
// For audio
if (frame->reserveAudio(44100, 2, AV_SAMPLE_FMT_S16, 1024)) {
// frame ready for audio data
}
// Switch frame mode to video:
frame->setMediaType(MediaType::Video)

◆ getCPUFormat()

AVPixelFormat Limef::frame::DecodedFrame::getCPUFormat ( ) const

Get the pixel format of the CPU-accessible data.

For CPU frames returns the frame's own format (e.g. AV_PIX_FMT_YUV420P). For GPU frames (VAAPI, CUDA) returns the format of the downloaded CPU cache (e.g. AV_PIX_FMT_NV12 for VAAPI, AV_PIX_FMT_NV12 for NVDEC). Returns AV_PIX_FMT_NONE if the frame is unavailable or the download fails.

Always call materializeToCPU() or getCPUData() first for GPU frames.

Set up frame as CPU NV12 from a NvBuf dma-buf fd (mmap, zero-copy).

mmaps the fd into userspace, sets data[0]/[1] directly into the mmap'd region, and attaches a custom AVBufferRef destructor that calls munmap + close. No pixel copy — the mmap IS the AVFrame buffer.

Caller must NOT close dma_fd after this call.

Set up frame as a non-owning CPU NV12 view into pre-mapped NVMM memory.

Used by V4L2NVDecoder's EXPBUF-at-setup path: CAPTURE slot CPU pointers are established once in setupCapture() and outlive individual frames. The V4L2NVDecoder owns the memory — this frame holds a no-op AVBufferRef so that AVFrame reference-counting does not free the mapping on unref.

Pointers remain valid until V4L2NVDecoder re-queues the slot via the next status() call (hold/release contract validated in playground/jetson/2/).

Parameters
widthFrame width
heightFrame height
y_ptrPre-mapped Y-plane CPU pointer (owned by V4L2NVDecoder)
uv_ptrPre-mapped UV-plane CPU pointer (owned by V4L2NVDecoder)
y_szY-plane size in bytes
