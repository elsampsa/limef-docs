Detailed Description

Composite filter that canonizes a stream for WebRTC delivery.

Chains: CodecAssertFrameFilter → RTPMuxerFrameFilter

WebRTC codec constraints (extremely strict)

RFC 8834 mandates specific codec support in all WebRTC implementations:

Video Audio Notes
H264 Opus Most common in practice; Baseline profile recommended
H264 PCMU G.711 μ-law; mandatory per RFC 8834
H264 PCMA G.711 A-law; mandatory per RFC 8834
H264 — Video-only
VP8 Opus Mandatory video codec per RFC 8834
VP8 PCMU
VP8 PCMA
VP8 — Video-only
VP9 Opus Widely supported
VP9 — Video-only
AV1 Opus Chrome 90+, Firefox 93+
AV1 — Video-only

Not supported by WebRTC browsers:

  • AAC — not in the WebRTC spec; Safari's WebRTC does not accept it
  • MP3 — not in the WebRTC spec
  • H265 — not mandatory; Safari supports it but Chrome/Firefox do not

The downstream is WebRTCServerThread which expects SDPFrames and RTPFrames.

Example:

WebRTCMuxerFrameFilter webrtc_muxer("webrtc_muxer");
encoder.cc(webrtc_muxer).cc(webrtc_server.getInput());
