◆ HWAccel

enum class Limef::HWAccel
strong

Hardware acceleration backends.

Note: This is for FFmpeg-based hardware acceleration only. V4L2 backend is separate (use V4L2EncoderParams/V4L2NVDecoderParams instead).

Note: NONE (not None) is used to avoid conflict with the X11 macro None=0L.

Enumerator
NONE 

Software encoding/decoding (no hardware accelerator)

VAAPI 

Intel/AMD hardware via VAAPI.

CUDA 

NVIDIA hardware via NVENC/NVDEC.

◆ isCUDARuntimeAvailable()

bool Limef::isCUDARuntimeAvailable ( )

Check if the CUDA runtime is available (at least one GPU present)

Unlike isHWAccelAvailable(HWAccel::CUDA), this does NOT require FFmpeg to be compiled with CUDA hwcontext support (CONFIG_CUDA). Use this when you only need raw CUDA operations: cudaMemcpy, kernel launches, BufferLocation::CUDA frames (TensorFrame GPU path, DecodedUploadFrameFilter, DecodedFrameFifo with CUDA target, CUDAScaleFrameFilter).

On Jetson, FFmpeg is intentionally built without CUDA (video codec uses V4L2), but the CUDA runtime is fully available — this returns true there while isHWAccelAvailable(HWAccel::CUDA) returns false.

Returns false when built without -Dcuda_native=ON (LIMEF_CUDA not defined).
