Detailed Description

A (video, audio) codec pair used by CodecAssertFrameFilter.

Use AV_CODEC_ID_NONE for either field to mean "don't check this track type". If the source has no stream of that type the field is treated as AV_CODEC_ID_NONE.

Examples:

CodecPair{AV_CODEC_ID_H264, AV_CODEC_ID_AAC} // H264 video + AAC audio
CodecPair{AV_CODEC_ID_H264, AV_CODEC_ID_NONE} // H264 video, any/no audio
CodecPair{AV_CODEC_ID_NONE, AV_CODEC_ID_OPUS} // any/no video, Opus audio
