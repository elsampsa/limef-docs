Detailed Description

Converts any CPU DecodedFrame → TensorFrame (c, h, w) UInt8 via libswscale.

Colour input → GBRP intermediate → CHW(3, H, W) via permuted dst[] pointers (zero extra copy). Greyscale input → GRAY8 → CHW(1, H, W) directly.

ChannelOrder::RGB → channels [R, G, B] in slots [0, 1, 2]. ChannelOrder::BGR → channels [B, G, R] in slots [0, 1, 2].
