Detailed Description

V4L2 device capability scanner.

Author
Sampsa Riikonen
Date
2026
Version
1.6.1

Queries all /dev/video* devices and returns their M2M codec and pixel format capabilities expressed in FFmpeg terms (AVCodecID, AVPixelFormat).

Typical usage — let tests auto-discover hardware instead of hardcoding paths:

auto devs = Limef::v4l2::scanDevices();
auto enc = findEncoder(devs, AV_CODEC_ID_H264);
auto dec = findDecoder(devs, AV_CODEC_ID_H264);
if (!enc || !dec) { skip_test(); return; }
