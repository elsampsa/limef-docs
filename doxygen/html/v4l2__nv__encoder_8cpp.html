LIMEF_V4L2_NV path (Jetson Orin NVENC):

  • Device: /dev/v4l2-nvenc via v4l2_open()
  • OUTPUT: V4L2_MEMORY_DMABUF — NvBufSurface PL fds registered via EGL+CUDA
  • CAPTURE: V4L2_MEMORY_MMAP — EXPBUF fallback required (NVMM-backed)
  • Input fourcc: V4L2_PIX_FMT_NV12M (multiplanar, 2 planes)
  • S_FMT ordering: CAPTURE must be set BEFORE OUTPUT
  • Input frames: AV_PIX_FMT_CUDA; D2D cudaMemcpy2D into EGL CUDA write ptrs
