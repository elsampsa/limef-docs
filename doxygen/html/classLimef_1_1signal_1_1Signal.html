Detailed Description

Signal base class.

Signals are encapsulated into SignalFrames and they are used to inform Thread's and downstream framefilters about actions and parameters they should do and use.

Use the SIGNAL_CLASS(ClassName) macro in every concrete subclass to implement getSignalClass(), clone(), and staticSignalClass() (used by Signal::as), for example:

class MySignal : public Signal {
SIGNAL_CLASS(MySignal)
public:
...
};
