Detailed Description

V4L2 Memory-to-Memory Encoder implementation.

Author
Sampsa Riikonen
Date
2025
Version
1.6.1

Uses the stateful V4L2 M2M API for hardware encoding. Works with:

  • vicodec (virtual codec for testing, uses FWHT)
  • Jetson hardware encoders (H.264, H.265) via LIMEF_V4L2_NV path
  • Other V4L2 M2M capable devices

When LIMEF_V4L2_NV is defined, the encoder uses the DMABUF+EGL+CUDA path:

  • OUTPUT queue: V4L2_MEMORY_DMABUF with NvBufSurface pitch-linear fds
  • CAPTURE queue: V4L2_MEMORY_MMAP with EXPBUF fallback (NVMM-backed)
  • Input frames: AV_PIX_FMT_CUDA (GPU frames from NVDEC or CUDA kernels)
  • D2D cudaMemcpy2D from frame CUDA ptrs into EGL-registered CUDA write ptrs
