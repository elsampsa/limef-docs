Detailed Description

Rate-limit payload frames by minimum inter-frame interval.

Forwards a payload frame (Packet, Decoded, Tensor) downstream only when at least interval microseconds have elapsed since the last forwarded payload frame, as measured by the frame's absolute timestamp.

  • Non-payload frames (Signal, Codec, Stream, SDP, RTP, Info, …) pass through unconditionally.
  • Payload frames with an invalid absolute timestamp pass through unconditionally.
  • The very first payload frame always passes through (no prior reference point).

Two orthogonal controls:

  • Rate-limiter (setState / setInterval): drops frames that arrive too soon after the previous forwarded frame.
  • Gate (open / close): drops all payload frames when closed, regardless of timestamps or the rate-limiter state.

All control methods are mutex-protected and safe to call from any thread.

Rate-limiting — cap 100 fps sensor to 10 fps

using namespace std::chrono_literals;
ThrottleFrameFilter throttle("throttle", 100'000us); // 100 ms → max 10 fps
camera.cc(throttle).cc(encoder);

Pass-through — enable/disable rate-limiting at runtime

throttle.setState(false); // disable rate-limiting: all payload frames flow freely
throttle.setState(true); // re-enable rate-limiting

Gate — block and resume the stream

throttle.close(); // drop all payload frames
// ... do something ...
throttle.open(); // resume; next frame passes immediately (timestamp reset)

Adjust interval on the fly

throttle.setInterval(200); // slow down to max 5 fps
throttle.setInterval(0); // pass every frame (still checks timestamps; use setState(false) for zero overhead)

Close the gate — drop all payload frames until open() is called.

Acts independently of the rate-limiter (setState). When the gate is closed, no payload frames reach downstream regardless of timestamps or the enabled flag. Non-payload frames (Signal, Codec, Stream, Info, …) still pass through. Thread-safe.

◆ setInterval()

void Limef::ff::ThrottleFrameFilter::setInterval ( int  interval_ms)
inline

Change the minimum inter-frame interval.

Sets the minimum time (in milliseconds) that must elapse between two consecutively forwarded payload frames. Setting 0 ms passes every frame (since any delta ≥ 0), but still incurs the timestamp check overhead; prefer setState(false) for a true pass-through. Thread-safe; takes effect on the next go() call.

◆ setState()

void Limef::ff::ThrottleFrameFilter::setState ( bool  enabled)
inline

Enable or disable the rate-limiter.

When enabled (default), payload frames are forwarded only when the inter-frame interval condition is met. When disabled, all payload frames pass through immediately with no timestamp check — equivalent to removing the filter from the chain. Non-payload frames are unaffected by this flag. Thread-safe.
