Detailed Description

Count DecodedFrames and report count + fps on demand.

All frames are passed downstream unchanged. Only DecodedFrames (FrameClass::Decoded) are counted. Timing starts on the first DecodedFrame seen.

report() and getCount() are safe to call from any thread.

Example:

CountDecodedFrameFilter counter("counter");
camera.getOutput().cc(counter);
// ... run for a while ...
counter.report(); // logs: "counter: 150 frames in 10.0s → 15.0 fps"
