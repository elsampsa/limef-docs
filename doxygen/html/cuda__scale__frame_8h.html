Detailed Description

CUDAScaleFrameFilter — GPU bilinear resize (and optional format convert) of NV12 DecodedFrames.

Author
Sampsa Riikonen
Date
2026
Version
1.6.1

Input: BufferLocation::CUDA or CUDA_FFMPEG, NV12 or YUV420P layout. Output: BufferLocation::CUDA, NV12 or YUV420P, at the configured target resolution.

Set output_format = AV_PIX_FMT_YUV420P to scale AND de-interleave the NV12 UV plane into separate planar U/V channels in a single GPU pass. The output frame then carries format = AV_PIX_FMT_YUV420P with CUDA device pointers — pass it through DecodedDownloadFrameFilter to obtain a CPU YUV420P frame ready for VP8/libvpx encoding.

dst_width / dst_height == 0 uses the source dimension unchanged. When both are 0, the input is already plain CUDA NV12, and output_format == NV12, the frame passes through untouched.

Non-video frames and non-CUDA frames pass through unchanged.

// NV12 resize only (default):
CUDAScaleFrameFilter scale("scale", {1280, 720});
// Resize + convert to YUV420P for VP8:
CUDAScaleParams sp(1280, 720, AV_PIX_FMT_YUV420P);
CUDAScaleFrameFilter scale("scale", sp);
DecodedDownloadFrameFilter dl("dl");
scale.cc(dl); // dl emits CPU YUV420P
