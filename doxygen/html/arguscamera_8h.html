Overview

ArgusCameraThread captures frames from a CSI camera (e.g. Raspberry Pi v2 / IMX219) connected to a Jetson Orin using the NVIDIA Argus API. Argus provides full ISP processing (AE, AWB, tone mapping) and delivers NV12 frames as dma-buf fds via the IImageNativeBuffer extension.

Requirements

  • NVIDIA Jetson with libargus (nvidia-l4t-camera package)
  • nvargus-daemon running (systemctl start nvargus-daemon)
  • Build with -Dargus_camera=ON

Output Frames

  • StreamFrame: Sent once at startup with video dimensions and NV12 pixel format
  • DecodedFrame: NV12 frames in CPU or CUDA memory depending on ArgusCameraContext::output_location. The NvBuf dma-buf fd is consumed internally — downstream never sees a DMA_CPU frame.
